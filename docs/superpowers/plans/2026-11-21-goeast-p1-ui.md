# GoEast P1 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax.

**Goal:** Explain a $1.99 one-time career report and give authorized users a private, same-cast fulfillment UI; keep Preview-only synthetic walkthrough separate.

**Architecture:** Reuse one report renderer and fixed example content. Gate the purchase offer server-side, use checkout only via the same-origin backend and render private API responses uncached. Preview walkthrough uses only React UI state.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind, Vitest.

**Spec:** GoEast-TASK-P1-One-Time-Decision-Report.md (Library v1).

## Global constraints
- USD 1.99 once (199 cents), English career case only, Pro subscription unchanged.
- Production purchase remains off; browser walkthrough Preview-only and clearly synthetic.
- Never add private question, cast or note to analytics or URLs; omit private lookup results from public markup.

## Review focus
- Quote appears only after a valid cast and server-side auth and offer gating.
- Repeated clicks are guarded; completed checkout routes to the original order without logging another checkout.
- Pending is not paid; retries never start checkout; refunded status hides report and action note.
- No claims of live sales or verified payment from the synthetic walkthrough.
- Real account use and test payment remain gated on backend isolation, not inferred from UI behavior.
