## 3. 引文程序化与英文下架

1. **模型上下文**（`classicalTextBlock()`）：只传已核验中文经文（本卦；追问路径同样），标签为"CONTEXT for interpretation only"；规则改为**"禁止复现引文——页面由程序展示原文，模型只解释"**；不再声称英文字段出自谁；缺失文本→明确"不可用、禁止凭记忆重构"。
2. **页面**：传统文本区块只从数据字段渲染（详情页/每日一卦/结果页，含变卦）；三区分清晰——**传统文本**（程序渲染+《周易》来源+校勘日期）/ **AI 解读**（模型输出，标注 AI）/ **英文**（统一显示"暂未核验，暂不展示"）。
3. **英文下架**：全部 128 条英文字段来源未证实（含此前"GoEast 自写"的断言本身不可证），已从一切公开展示与模型上下文移除；逐条状态表与恢复条件见 `docs/iching-english-source-status.md`。meta description / JSON-LD `text` 改用中文原文。
4. **历史解读保护**：历史结果的 `aiResponse`（含旧模型文字）照旧渲染于 **AI 区块**（ResultView 的 TRADITIONAL TEACHING 小节位于 "AI Interpretation" 大节下、带 AI 免责声明）——从未被标注为已核验原文，本次不重标、不删除；"传统文本"区块只读数据库字段（有测试固化该契约）。
5. 上一轮报告（`docs/2026-11-13-iching-collation-report.md`）中"英文为 GoEast 自写、未复制已出版译文"的断言已在文件内更正（见其附记）。
